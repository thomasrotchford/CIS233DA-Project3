Flexbox Cheatsheet

Terminology

Flex Container
element that uses Flexbox to arrange its child elements.
Flex Items
direct children of a flex container
Flex Directions
direction in which flex items are arranged, either in rows or columns.
Main axis
primary axis along which flex items are placed
Main size properties
width or height properties that control an item's size along the man axis
Cross axis
axis perpendicular to the main axis
Cross size properties
width or height properties that control an item's size along the cross axis

Properties

Flex Container Properties

display
flex; /* creates a block-level flex container */
inline-flex; /* creates a flex container that behaves like an inline element */
flex-direction
row; /* arranges items horizontally in the normal direction */
row-reverse; /* arranges items horizontally in reverse order */
column; /* stacks items vertically */
column-reverse; /* stacks items vertically in reverse order */
flex-wrap
nowrap; /* keeps items on one line */
wrap; /* moves items to another line when needed */
wrap-reverse; /* wraps items with the cross-axis direction reversed */
flex-flow
row nowrap; /* arranges items in a row without wrapping */
row wrap; /* arranges items in a row and allows wrapping */
column nowrap; /* stacks items in one column without wrapping */
column wrap; /* stacks items vertically and allows additional columns */
row-reverse wrap-reverse; /* reverses the row and wrapping directions */
justify-content
flex-start; /* aligns items to the main start */
flex-end; /* aligns items to the main end */
center; /* centers items along the main axis */
space-between; /* puts equal space between items */
space-around; /* adds equal space around each item */
space-evenly; /* makes all spaces between and around items equal */
align-items
stretch; /* stretches items across the cross axis when their size allows it */
flex-start; /* aligns items to the cross-axis start */
flex-end; /* aligns items to the cross-axis end */
center; /* centers items along the cross axis */
baseline; /* lines up items using their text baselines */
align-content
stretch; /* stretches flex lines to fill available space */
flex-start; /* groups flex lines at the cross-axis start */
flex-end; /* groups flex lines at the cross-axis end */
center; /* centers flex lines along the cross axis */
space-between; /* distributes extra space between flex lines */
space-around; /* distributes space around each flex line */
space-evenly; /* distributes equal space between and around flex lines */

Flex Item Properties

order
0; /* uses the default ordering position */
1; /* places the item after items with lower order values */
-1; /* places the item before items with higher order values */
flex-grow
0; /* prevents the item from growing to fill extra space */
1; /* allows the item to grow and share extra space */
2; /* gives the item twice the growth share of an item set to 1 */
flex-shrink
0; /* prevents the item from shrinking through Flexbox */
1; /* allows the item to shrink when space is limited */
2; /* makes the item shrink more aggressively than an equally sized item set to 1 */
flex-basis
auto; /* uses the item's main size property or content size as its starting size */
0; /* starts the item at zero size before flex growth is applied */
200px; /* sets the starting main-axis size to 200 pixels */
50%; /* sets the starting size to half the container's definite main size */
content; /* bases the starting size on the item's content */
flex
none; /* prevents the item from growing or shrinking */
auto; /* lets the item grow or shrink from its automatic starting size */
initial; /* uses the default behavior of not growing but allowing shrinking */
1; /* lets the item grow and shrink with a zero flex basis */
0 1 200px; /* prevents growth, allows shrinking, and starts at 200 pixels */
align-self
auto; /* follows the container's align-items setting */
stretch; /* stretches this item across the cross axis when possible */
flex-start; /* aligns this item to the cross-axis start */
flex-end; /* aligns this item to the cross-axis end */
center; /* centers this item along the cross axis */
baseline; /* aligns this item's text baseline with other items */
